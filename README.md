# Aug2026-Grok_Bot

Trails on **Grok Bot** — Aug 2026 — S Gattani.

Grok Bot is xAI’s durable AI teammate product: named Bots on a persistent cloud computer that use apps, files, and connectors to finish real work end to end (with your approval on consequential actions).

## Best use cases (as of this trail)

See **[USE_CASES.md](./USE_CASES.md)** for the strongest official roles and starter prompts:

| Role | Owns |
| ---- | ---- |
| Sales Outbound | Account research + review-ready outreach |
| Talent Scout | Sourcing + outreach drafts (no contact until approved) |
| Paid Media | Campaign monitoring + budget recommendations |
| Expense Manager | Weekly reconciliation + follow-up drafts |
| Product Performance | Evidence-backed performance investigations |
| Bug Reproduction | Staging repro packs from bug reports |
| Account Health | Ranked churn/expansion watch lists |
| Chief of Staff | Source-linked priority digest |

Rule of thumb: give each Bot a **repeatable outcome**, start with **read-and-prepare**, then promote to a skill/routine once the output is reliably reviewable.
