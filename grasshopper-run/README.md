# Grasshopper Run (32-Bit)

Side-scrolling browser game: guide the Family Guy–style grasshopper to a finish line **10 screen-widths** away while fighting Stewie-styled ants.

## Play

Open `grasshopper-run/index.html` in a browser, or from this folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Controls

| Key | Action |
|-----|--------|
| ← → / A D | Move |
| Space / W / ↑ | Jump |
| X / Z / Ctrl | Shoot red–yellow fire |
| P | Pause |

## Goal

Reach the checkered finish line at the end of a 10-screen grassland. Shoot ants (2 hits each). You have 3 HP.
